01 / FEEDBACK

Nút bấm có cảm xúc

Ba trạng thái, một phản hồi rõ ràng. Hover nâng nút lên 3px; active nén nút lại như một cú bấm vật lý.

THỬ TƯƠNG TÁC Hover để nâng · nhấn để thu nhỏ
button.css
.button {
  transition: transform 260ms cubic-bezier(.22, 1, .36, 1),
    box-shadow 260ms cubic-bezier(.22, 1, .36, 1),
    background-color 260ms cubic-bezier(.22, 1, .36, 1);
}
.button:hover { transform: translateY(-3px); }
.button:active { transform: scale(.95); }

02 / LOADING

Chờ cũng cần đẹp

Spinner CSS thuần với cạnh trên khác màu, quay 360 độ vô hạn bằng animation tuyến tính.

Portfolio đã sẵn sàng 12 dự án · cập nhật vừa xong
spinner.css
.spinner {
  border: 3px solid #dce1d4;
  border-top-color: #587b31;
  border-radius: 50%;
  animation: spin .8s linear infinite;
}
@keyframes spin {
  to { transform: rotate(360deg); }
}

03 / SCROLL REVEAL

Xuất hiện đúng lúc

AOS thêm hiệu ứng khi section đi vào vùng nhìn. Các phần bên dưới chính là ví dụ đang chạy khi bạn cuộn trang.

AQuan sátNội dung đi vào khung nhìn
BDẫn mắtTiết lộ theo nhịp có chủ đích
CTiết chếChỉ dùng khi tăng độ rõ ràng
AOS VIA CDN

Thêm stylesheet và script từ CDN, gọi AOS.init(), rồi đặt data-aos="fade-up" lên phần tử cần reveal.

<section data-aos="fade-up">...</section>
<link href="https://unpkg.com/aos@2.3.4/dist/aos.css" rel="stylesheet"> <script src="https://unpkg.com/aos@2.3.4/dist/aos.js"></script> <script>AOS.init({ once: true });</script> <section data-aos="fade-up">...</section>

04 / PERFORMANCE

Chuyển động nhẹ hơn

Rê chuột lên hai vùng để so sánh. Một bên thay đổi vị trí layout; bên còn lại dịch chuyển bằng transform.

01LAYOUT PROPERTIESCŨ
MOVE

Thay đổi top / left có thể khiến trình duyệt tính toán lại layout.

transition: top .3s, left .3s;
top: -10px; left: 5px;
02TRANSFORMTỐI ƯU
MOVE

transform thường tránh layout lại. Trình duyệt có thể composite riêng; không phải lúc nào cũng đảm bảo chạy trên GPU.

transition: transform .3s cubic-bezier(.25,.46,.45,.94);
transform: translate(5px, -10px);

↗ Ưu tiên transform và opacity cho animation; kiểm tra hiệu năng thực tế bằng DevTools.
